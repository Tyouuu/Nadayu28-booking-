# Next.js Migration — Phase A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Vite build/dev toolchain and the hand-rolled client-side `NavigationContext` router with a Next.js App Router scaffold, and get exactly one route (`/dashboard`) working end to end, on branch `nextjs-migration`.

**Architecture:** Next.js App Router with client components throughout (no Server Components/SSR data fetching in this phase — every component keeps its existing `useEffect` + `supabase-js` data fetching unchanged). `currentView` string state is replaced by real URL segments of the same names (`/dashboard`, `/billing`, ...). A new `useAppNavigate()` hook wraps `useRouter().push` so every existing `navigate('id')`/`setCurrentView('id')` call site becomes a one-line `nav('id')` swap.

**Tech Stack:** Next.js (App Router, latest stable), React 19, TypeScript, Tailwind CSS (build-time, replacing the CDN script), `next/font/google` for Inter.

## Global Constraints

- This plan runs entirely on branch `nextjs-migration`. No step in this plan pushes to `origin` or deploys to Vercel — Phase A ends with local commits only.
- Only `/dashboard` becomes a real working route this phase. Every other nav item will 404 on this branch until Phase B (separate future work) — this is expected, not a bug to fix here.
- No visual changes — every ported page must look pixel-identical to the current Vite version.
- No data-fetching architecture changes — components keep using `useEffect` + `supabase-js` exactly as today.
- No test suite exists in this repo. Verification per task is `npx tsc --noEmit` plus `npm run build` (which becomes `next build` starting in Task 1).

- [ ] **Step 1: Fix I18nContext's SSR-unsafe localStorage read**

`contexts/I18nContext.tsx` currently calls `localStorage.getItem(...)` directly inside `useState(getInitialLocale)` (line 30's initializer). Next.js pre-renders client components on the server for the initial HTML pass, where `localStorage` does not exist — this throws during `next build`/`next dev`. Fix it to be SSR-safe by reading the saved locale after mount instead of during the initial render.

Add `'use client';` as the first line of the file if not already effectively required (it uses hooks, so it must be a client component — Next.js infers this from the `'use client'` directive, which this file currently lacks since Vite never needed it).

Change:

```ts
function getInitialLocale(): Locale {
  const saved = localStorage.getItem('nadayu28_locale') as Locale | null;
  if (saved && translations[saved]) return saved;
  return 'en';
}

export const I18nProvider: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const [locale, setLocaleState] = useState<Locale>(getInitialLocale);
```

to:

```ts
export const I18nProvider: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const [locale, setLocaleState] = useState<Locale>('en');

  useEffect(() => {
    const saved = localStorage.getItem('nadayu28_locale') as Locale | null;
    if (saved && translations[saved]) setLocaleState(saved);
  }, []);
```

- [ ] **Step 1: Create app/page.tsx**

Root route: if logged in, redirect to `/dashboard`; otherwise render `<Login>`, reproducing today's `App.tsx` `onLogin` callback (role-based redirect target — only `/dashboard` exists this phase, `/management` and `/security` will 404 until Phase B, which is expected).

```tsx
'use client';

import { useEffect } from 'react';
import { useRouter } from 'next/navigation';
import { useAuth } from '../contexts/AuthContext';
import { Login } from '../components/Login';
import { UserRole } from '../types';

export default function RootPage() {
  const { isLoggedIn, isLoading, login } = useAuth();
  const router = useRouter();

  useEffect(() => {
    if (!isLoading && isLoggedIn) {
      router.replace('/dashboard');
    }
  }, [isLoading, isLoggedIn, router]);

  if (isLoading || isLoggedIn) {
    return (
      <div className="min-h-screen flex items-center justify-center bg-nadayu-bg">
        <div className="text-center">
          <div className="w-12 h-12 border-4 border-nadayu-border border-t-nadayu-accent rounded-full animate-spin mx-auto mb-4"></div>
          <p className="text-nadayu-muted text-sm">Loading...</p>
        </div>
      </div>
    );
  }

  return (
    <Login
      onLogin={async (role: UserRole) => {
        await login(role);
        router.push(role === UserRole.MANAGEMENT ? '/management' : role === UserRole.SECURITY ? '/security' : '/dashboard');
      }}
    />
  );
}
```
